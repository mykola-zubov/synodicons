# 📖 Інструкція користувача: Цифрова ономастична лабораторія синодиків Слепченського монастиря (XVI–XVII ст.)

**Цифрова лабораторія** — це спеціалізоване дослідницьке середовище для палеографічного аналізу, кодикологічної верифікації, ономастичної розмітки та автоматизованого укладання частотних словників македонських рукописних пом'янників XVI–XVII ст. за міжнародним стандартом **TEI P5 (Text Encoding Initiative)**.

Платформа об'єднує два споріднені списки пом'яника Слепченського монастиря св. Іоанна Предтечі:

1. **Одеський список 1/116** (ОННБ, Ркп 1/116, 193 арк., XVI–XVII ст.)
2. **Софійський список 1015** (НБКМ, № 1015, XVI–XVII ст.)

## 1. Перемикання рукописів та загальний інтерфейс

Інтерфейс розділено на три функціональні панелі:

- **Ліва панель:** інтерактивне полотно манускрипту з фотографіями високої роздільної здатності, верхнім віконцем-кропом активного рядка та інструментами збільшення.
- **Середня панель:** зведений покажчик усього кодика (живий алфавітний словник усіх слів пам'ятки з фільтрами).
- **Права панель:** список рядків відкритого аркуша та адаптивна форма наукової анотації.

### 🔄 Як перемкнути рукопис

У лівому кутку верхньої шапки розташовано селектор кодиків:

- `[ Одеський 1/116 ▾ ]` — перемикає платформу на роботу з кодиком Ркп 1/116.

- `[ Софійський 1015 ▾ ]` — перемикає на кодик НБКМ 1015.

При перемиканні система автоматично завантажує відповідний XML-файл, правильні фотографії та індивідуальну кодикологічну шкалу пам'ятки.

## 2. Кодикологічна шкала (Codex Map) та пагінація

Під шапкою розміщено **інтерактивну кольорову шкалу структури кодика**:

- Кожен сегмент шкали позначає окремий зошит або тематичний розділ.

- **Кольорове кодування:**
  - 🔴 **Червоний:** Ієрархія та чин дяконства.
  - 🔵 **Синій:** Чоловічий поминальник (Оригінальні зошити XVI ст.).
  - 🟢 **Зелений:** Жіночий поминальник (Оригінальні зошити XVI ст.).
  - 📋 **Блакитний / Бірюзовий:** Копійні зошити писця зі знаком $\tilde{\imath}$.
  - ⚪ **Сірий:** Позасистемні та пізніші приписки XVII ст.

### 🖱️ Взаємодія зі шкалою

- **Наведення миші:** показує точні межі аркушів, назву розділу та писця.
- **Клік на сегмент:** миттєво відкриває початковий розворот цього розділу.
- **Білий бігунок:** позначає точне положення поточної відкритої сторінки в межах усього манускрипту.

## 3. Робота з зображенням (Zoom, Pan, Лупа)

Полотно манускрипту зліва працює за стандартами графічних редакторів та системи Transkribus:

- **Збільшення / Зменшення (Zoom):**
  - Покрутіть **коліщатко миші** над аркушем або зробіть **рух двома пальцями (pinch) на тачпаді**. Зум автоматично фокусується в точку під курсором.
  - Або використовуйте кнопки `[ + ]` та `[ − ]` у лівому нижньому кутку полотна.
- **Переміщення аркуша (Pan / Drag):**
  - Затисніть **ліву кнопку миші** на зображенні та вільно перетягуйте аркуш у будь-який бік.
- **Кнопка `[ ⟲ Скинути ]`:** повертає аркуш у початковий вигляд, ідеально вписаний у вікно.
- **Кнопка `[ 🔍 Лупа ]`:** вмикає режим круглого оптичного скла з 3-кратним палеографічним збільшенням для розгляду складних літер та виносних титлів.

## 4. Зведений покажчик корпусу (Corpus Index)

Середня колонка містить повний реєстр усіх слів пам'ятки:

- **🔤 Алфавітне сортування (А–Я):** усі середньовічні варіанти графіки (`ѡ, ѣ, ꙗ, ѧ, ꙋ, ѫ, ѳ, ї, і, ѵ, ѯ`) автоматично нормалізовані до сучасного фонетичного алфавіту. Тому форми `їѡанна`, `іѡнъ`, `иоань` стоять разом на літеру **І / И**.
- **Фільтр сутностей:**
  - `Антропоніми` — показує лише імена людей (`person`).
  - `Топоніми` — показує географічні назви поселень (`place`).
  - `🖋️ Первинний (#h1)` / `✍️ Приписки (#h2)` — фільтрація за шарами письма.
  - `⚠️ Нерозмічені` — виводить список слів, які ще не мають леми (ідеально для методичної щоденної розмітки).
- **Пошук на льоту:** введіть будь-яку основу в поле під селектором для миттєвого фільтрування списку.
- **Клік на будь-який рядок покажчика** $\to$ система миттєво відкриває потрібний аркуш і підсвічує слово червоною рамкою на манускрипті.

## 5. Наукова анотація та лематизація імен

Коли ви обираєте рядок, у правій нижній панелі відкривається форма:

1. **Тип сутності (TEI Type):**
   - *Особа (`person`)* — для імен людей.
   - *Топонім (`place`)* — для сіл, міст і монастирів (поля статі й сану для них автоматично приховуються).
   - *Титул (`status`)* — для церковних і світських звань.
   - *Неясно (`unclear`)* — для пошкоджених чи нерозбірливих фрагментів.
2. **Шар письма (TEI `@hand`):**
   - `🖋️ Основний (#h1)` — каліграфічний текст основного писця з кіноварними ініціалами (XVI ст.).
   - `✍️ Приписка (#h2)` — пізніші нашарування, маргіналії на полях та міжрядкові вставки (XVII ст.).
3. **Транскрипція:**
   - Дозволяє виправити описку писця або помилку OCR прямо у формі зі збереженням XML-структури.
4. **Лема (Початкова форма):**
   - Вказується нормалізована канонічна македонська форма імені (наприклад: *Јован, Никола, Димитар, Ангелина, Грозда*).
   - **Автодоповнення:** вбудована наукова база на 320+ македонських імен підказує лему вже після першої літери та **автоматично виставляє стать**.
5. **Граматична стать (`sex` за ISO 5218):** `Чоловіча (1)` або `Жіноча (2)`.
6. **Соціальна роль / Сан (`role`):** `мирянин`, `священнослужитель`, `монах`, `правитель`, `воїн`.

## 6. Швидка робота та гарячі клавіші

Для максимальної швидкості анотації реалізовано безмишний робочий цикл:

| Клавіша | Дія |
| :--- | :--- |
| **`Enter`** (у полі леми) | Зберігає поточне слово в XML та автоматично переходить до наступного рядка. |
| **`Ctrl + S`** (або **`Cmd + S`**) | Зберігає зміни поточного рядка без зміни фокусу. |
| **`↓` (Стрілка вниз)** | Перехід до наступного рядка на сторінці (автоматично центрує манускрипт). |
| **`↑` (Стрілка вгору)** | Перехід до попереднього рядка. |
| **`Esc`** | Закриває будь-яке відкрите модальне вікно (статистику або зіставлення). |

### ⚡ Пакетна авторозмітка («Розмітити всі такі в кодику)

Якщо ім'я (наприклад, `їѡанна` чи `петка`) зустрічається в рукописі 50 або 100 разів:

1. Заповніть лему (*Јован*) і стать (*чоловіча*) для одного рядка.
2. Натисніть зелену кнопку **`⚡ Розмітити всі такі в кодику`**.
3. Система за 0.1 секунди пролематизує всі ідентичні входження по всій пам'ятці, **зберігши при цьому індивідуальний шар письма (`hand`) кожного запису**.

## 7. Текстологічне зіставлення «Пліч-о-пліч» (Оригінал ↔ Копія)

Для кодика 1/116, де присутні паралельні копійні зошити писця $\tilde{\imath}$, впроваджено модуль текстологічної колокації:

1. Коли відкрито аркуш-копію (наприклад, `10a`) або оригінал (`161a`), у синій плашці над фото натисніть кнопку **`[ ⚖️ Зіставити пліч-о-пліч ]`**.
2. Відкриється синхронізована двостовпчикова таблиця:
   - **Зліва:** автентичний оригінал XVI ст.
   - **Справа:** копія писця $\tilde{\imath}$ XVII ст.
3. **Розумне вирівнювання (Sequence Alignment):**
   - Топоніми на полях (наприклад, `ѡхрид`) автоматично відсікаються, щоб не зміщувати порядок імен.
   - Пропущені копіїстом жіночі імена (*подрꙋжїе марїца*, *саррꙋ*) підсвічуються червоним: `— (пропущено в копії)`.
   - Однаково розташовані імена вирівнюються строго в один рядок.
4. **Миттєве маркування дублів:**
   - Натискайте кнопку **`[ 🚫 Дубль ]`** $\leftrightarrow$ **`[ ✅ Враховано ]`** навпроти будь-якого рядка копії, щоб одним кліком вилучити його з частотного словника або повернути назад.

## 8. Частотна статистика та експорт наукових словників

Усі результати розмітки доступні для миттєвого вивантаження в таблиці Excel / CSV (з кодуванням UTF-8 BOM для коректного відкриття кирилиці):

### 📊 Модальне вікно статистики

- **Загальний прогрес:** відсоток розмічених слів та абсолютна кількість.
- **Статеве співвідношення:** кількість та пропорція чоловічих і жіночих імен.
- **ТОП-10 найпопулярніших імен:** клік на будь-яке ім'я в топі миттєво відкриває всі його локалізації в кодику.
- **Перемикач `[ 🔬 Без дублів копій ]`:** показує реальну історичну кількість осіб без штучного подвоєння за рахунок копій.

### 📥 Окремі наукові словники (у шапці сайту)

1. **`📥 Словник імен` (`/api/export/anthroponyms`):**
   - Усі канонічні леми в алфавітному порядку.
   - Стать (`чол.` / `жін.`).
   - Загальна частота згадок у пам'ятці.
   - Розподіл частоти між первинним шаром (`#h1`) та приписками (`#h2`).
   - Повний перелік графічних варіантів написання з вказівкою частоти та аркушів кодику (наприклад: *агглина (8) [48a, 117a, 120b...]; ангелина (5) [33a, 93a...]*).
2. **`🗺️ Топоніми` (`/api/export/toponyms`):**
   - Алфавітний словник усіх географічних назв пам'ятки із загальною кількістю фіксацій та списком усіх аркушів.
3. **`📥 Повний датасет` (`/api/export/csv?dedup=1`):**
   - Повна база даних для кількісного та статистичного аналізу в R, Python або SPSS.
