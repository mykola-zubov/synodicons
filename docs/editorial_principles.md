# 📜 Принципи ономастичної нормалізації та кодування TEI P5

## 1. Засади лематизації

* **Нормалізація графічних дублетів:** середньовічні варіанти літер (`ѡ, ѣ, ꙗ, ѧ, ꙋ, ѫ, ѳ, ї, і, ѵ`) зводяться до канонічної македонської ономастичної норми за словниками Т. Стаматоського та Л. Станковської.
* **Збереження транскрипції:** оригінальне написання писця зберігається всередині тегу `<rs>`, а нормалізована лема фіксується в атрибуті `@lemma` (наприклад, `<rs type="person" lemma="Јован">їѡанна</rs>`).

## 2. Стандарти кодування TEI P5

* **Сутності:** `<rs type="person">` (імена), `<rs type="place">` (топоніми), `<rs type="status">` (титули).
* **Граматична стать:** стандарт ISO 5218 (`sex="1"` — чоловіча, `sex="2"` — жіноча).
* **Стратиграфія почерків:** атрибут `hand="#h1"` (основний писець XVI ст.) та `hand="#h2"` (приписки XVII ст.).
* **Дедуплікація копій:** атрибут `ana="#duplicate"` для вилучення паралельних записів із наукової статистики.
